===============================================================
  BTP Pipeline — HOW TO RUN (Step by Step)
  IIT Kharagpur | Wheel Wander & Lateral Offset Analysis
===============================================================


STEP 1 — Install all dependencies  (do this ONCE)
--------------------------------------------------
  pip install -r requirements.txt


STEP 2 — Run a single video  (first time — calibration required)
-----------------------------------------------------------------
  python pipeline.py --source "f:\BTP\videos\094147-00015-M.TS" --model yolo11x --conf 0.20 --imgsz 1280 --calib-file calib.json

  >> When the window opens, you will click 8 points total:
       [Phase 1]  Click 4 road corners in order:
                    P1 = Far Left,  P2 = Far Right,
                    P3 = Near Left, P4 = Near Right
       [Phase 2]  Click 2 points along the RIGHT road boundary
       [Phase 3]  Click 2 points to draw the measurement gate line

  >> The output video is written at 24 fps, with annotated offset rulers and wheel markers.
  >> `--imgsz 1280` and `--conf 0.20` ensure accurate detection of bicycles, motorcycles, and 2-wheeler riders.
  >> Calibration is saved to calib.json automatically for future reuse.

  Keyboard controls while it runs:
    SPACE  = Pause / Resume
    E      = Export Excel + CSV right now
    S      = Save current frame as PNG
    R      = Redo calibration
    Q      = Quit (auto-saves everything on exit)

  Output files produced:
    094147-00015-M_annotated.mp4      (annotated video)
    094147-00015-M_offsets.xlsx       (Excel measurements)
    094147-00015-M_offsets.csv        (CSV measurements)


STEP 3 — Run ALL videos in batch automatically
---------------------------------------------------------------------
  python batch.py --video-dir "f:\BTP\videos" --output-dir "outputs" --calib-file calib.json --model yolo11x --conf 0.20 --imgsz 1280

  >> Processes all videos one by one using saved calibration (or prompts on 1st video).
  >> All outputs go into:  outputs\<video_name>\


STEP 4 — Generate statistical analysis & charts
------------------------------------------------
  python analyze.py --csv outputs\*\*_offsets.csv --output-dir analysis

  Output files produced in  analysis\  folder:
    statistics.csv                    (summary stats table)
    wheel_wander_report.xlsx          (full Excel report)
    figures\01_distribution_overview.png
    figures\02_truck_wheel_wander.png
    figures\03_boxplot_by_type.png
    figures\04_lane_utilisation_heatmap.png
    figures\05_center_offset_timeseries.png
    figures\06_vehicle_distribution.png


STEP 5 — Automated Resumable Dataset Processing (Full Hierarchy)
---------------------------------------------------------------------
  python automate_dataset.py --root "f:\BTP\NH-19 1st and 2nd May" --output-dir outputs --calib-file calib.json --imgsz 640 --skip-frames 2

  >> Automatically traverses Section (LHS/RHS) -> Date (1st May/2nd May) -> Session -> Video.
  >> RHS / 2nd May is configured as a 3-lane road (10.5 m total width); other groups remain 2 lanes.
  >> The first RHS / 2nd May video creates its own 3-lane calibration, reused for that group.
  >> Maintains persistent progress in  outputs\checkpoint.json .
  >> Generates single Master Excel report at  outputs\master_dataset_report.xlsx .
  >> Automatically resumes from the exact interrupted video upon restart.
  >> Automatically runs analyze.py at the end to generate all statistical charts in outputs\combined_analysis\figures\ .

  NOTES:
    - Default road width = 7.0 m, lane width = 3.5 m. Change with --road-width / --lane-width.
    - `--skip-frames 2` provides 2x speedup on CPU. Use `--skip-frames 1` for full per-frame evaluation.
    - `--imgsz 640` is optimized for CPU speed. Use `--imgsz 1280` if extra small vehicle detail is needed.
    - All scripts must be run from the  f:\BTP\Autmn Sem\  directory.
